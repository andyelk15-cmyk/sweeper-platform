Version Control – Upgrade / Downgrade / Transfer Data

How it works: Save in Browser keeps data on this device only. Download Project Data creates a JSON backup file. Upload Project Data restores that file. Upgrade/Downgrade changes the interface level while keeping your project data where possible.

V1 Basic

Downgrade view

Recommended Use

  1. Enter site data in BOQ, Compliance, Actions, and Workflow.
  2. Click Save in Browser during normal use.
  3. Click Download Project Data before sending, upgrading, or moving device.
  4. On another device or newer Sweeper file, click Upload Project Data and select the JSON backup.
  5. Use V1/V2/V3 mode only as presentation levels — your real data stays in the project backup.
